# Descrição profissional

## Versão curta

**Fernando Lucoco Music — Web Audio Studio.** Desenvolvimento de uma aplicação web responsiva para gravação vocal directamente no navegador, utilizando `MediaRecorder API`, `MediaDevices API` e persistência local. Implementação de gestão de takes, reprodução, download, eliminação, presets visuais de produção e experiência mobile-first, com testes determinísticos de fluxos de áudio e documentação de QA.

## Nota de honestidade técnica

A versão actual não executa Auto-Tune, DSP, mixing, mastering, IA, contas, cloud storage ou sincronização. Esses itens estão documentados como roadmap e só devem ser acrescentados à descrição profissional depois de implementados e testados.
