# Estrutura do site

## Produto activo

`index.html` é a entrada pública do **Fernando Lucoco Music**, um estúdio vocal web-first. Contém a experiência de captura, gestão local, reprodução e preparação visual de takes.

## Ficheiros legados

`manutencao.html`, `python.html`, `redes.html` e `web.html` pertencem ao histórico do portfólio anterior. Não são páginas do produto musical e não devem ser apresentados como funcionalidades do Fernando Lucoco Music. Nesta etapa ficam preservados para não quebrar links antigos; uma futura limpeza poderá movê-los para uma área `legacy/` ou criar redireccionamentos documentados.

## Regra de publicação

Qualquer melhoria nova do estúdio deve ser feita primeiro em `index.html`, validada localmente, registada no README e publicada no deployment Vercel ligado à branch `main`.
